# Data Structure

> 初阶数据结构学习与实现，记录数据结构学习过程中的代码与理解。

---

## 📖 仓库介绍

本仓库主要用于学习与实现初阶数据结构。

所有数据结构均使用 C语言 动态实现，旨在通过代码实践理解数据结构的底层逻辑与核心思想。

内容涵盖线性结构、树结构以及经典排序算法，为后续算法与竞赛学习打下基础。
